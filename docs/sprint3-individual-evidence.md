
# Sprint 3 Individual Evidence Portfolio

## Project
FIVE-STAR Retail

## Individual Contribution

I developed and tested a local Express backend using Node.js. I created a SQLite database containing categories, products, users, orders, and order items tables. I tested the backend health endpoint and products API to confirm that the server was running and returning product information.

I also connected the product listing page to the API and tested adding products to the shopping cart, validating the cart, and completing checkout. The checkout process created an order, which I verified through the orders API and order items API.

## Technical Skills Demonstrated

- Node.js and Express backend setup
- SQLite database creation and sample data
- REST API testing
- Frontend and backend integration
- Shopping cart and checkout testing
- GitHub documentation and version control

## Evidence Collected

- Project folder structure
- Database tables and sample product records
- Backend server running locally
- Health check and products API responses
- Product listing and shopping cart pages
- Successful checkout and order creation
- GitHub branch and commit history

## Reflection

This work helped me understand how a frontend communicates with a backend API and how product and order information can be stored in a database. I gained practical experience running a local server, testing API responses, checking database records, and documenting development evidence. I also learned the importance of using GitHub branches to organise project work and track changes.
