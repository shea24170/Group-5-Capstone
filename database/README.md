# FIVE-STAR Retail System – Database

This folder contains the database files for the FIVE-STAR Retail System.

The database is based on the Week 4 Entity Relationship Diagram (ERD).

The eight approved entities are:
User
Category
Product
Cart
CartItem
Order
OrderItem
ContactMessage

The database supports customer accounts, products, shopping carts, orders, and customer contact messages.

This work forms part of Capstone B – Sprint 3.
